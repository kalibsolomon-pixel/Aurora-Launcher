# Borealis pilot asset

`borealis.webp` is an original AI-generated aurora image produced with OpenAI ImageGen for this Phase F request on 2026-09-28. It contains no Lunar/Dawn artwork and no downloaded third-party footage. The owner-supplied Aurora logo was not used as an input and remains unchanged.

Direction: photorealistic northern lights, fine mint/teal/violet curtains above dark distant mountains; quiet dark center/lower area; no text, logo, watermark or UI. Generated master: 1672×941. Bundled WebP: 92,030 bytes. The generated master remains in the local Codex image output; only the optimized asset is needed at runtime.

The still remains the reduced-motion and decode-failure fallback. The original camera drift and subsequent distortion prototype have been removed.

`borealis-loop.mp4` is a locally rendered loop requested by the owner on 2026-09-29, starting from this original artwork. It is **procedural light animation, not recorded footage or output from an image-to-video model**. Soft, irregular emission fields brighten and fade inside the original aurora silhouette. Broad smoothly interpolated patches replace linear phase bands, and a smooth response retains at least 68% of the original emission through dim phases to avoid dark striations. The overall curtains stay in place; there is no translation, camera movement or image warp. The landscape and sharp star detail remain fixed. The post-1.3.0 corrective candidate increases the light response because the 1.3.0 loop's changing illumination was difficult to perceive at launcher scale; the published 1.3.0 asset is unchanged.

The silent H.264/yuv420p video is 1920×1080 at 30 fps for 20 seconds (600 frames), upscaled from the original 1672×941 source. The corrective candidate is 4,613,649 bytes; SHA-256 `09f42752867c56a6b22fe761448ec4569d1566a28648b3c254cfab6967adbae9`. Integer temporal frequencies make the illumination periodic. Uncompressed frames at 0 and 20 seconds are identical; the encoded file omits the duplicate endpoint so playback does not hold an extra frame. The uncompressed seam step averages 0.01734/255 per channel versus 0.01737/255 for the first adjacent frame. No crossfade or reversed playback is used. All 600 encoded frames decode without errors.
Reproduce with `tools/visual/render-borealis.py --ffmpeg <executable> --output <mp4> --evidence <directory>`. Pillow and NumPy are offline authoring tools only; the application adds no dependency or per-frame JavaScript work. A local video decoder owns playback, the stored motion setting maps to 0.5–1.5× playback, focus loss/hidden state pauses playback, reduced motion uses the still, and unmounting releases the source. No third-party preview footage is bundled.

The original image was generated for this project, not taken from an external asset library; there is no third-party attribution dependency. No claim of exclusive copyright in AI-generated imagery is made.
