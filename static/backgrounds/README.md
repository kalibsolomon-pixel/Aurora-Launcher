# Borealis pilot asset

`borealis.webp` is an original AI-generated aurora image produced with OpenAI ImageGen for this Phase F request on 2026-09-28. It contains no Lunar/Dawn artwork and no downloaded third-party footage. The owner-supplied Aurora logo was not used as an input and remains unchanged.

Direction: photorealistic northern lights, fine mint/teal/violet curtains above dark distant mountains; quiet dark center/lower area; no text, logo, watermark or UI. Generated master: 1672×941. Bundled WebP: 92,030 bytes. The generated master remains in the local Codex image output; only the optimized asset is needed at runtime.

This is a **pilot still image with slow camera drift**, not filmed/evolving aurora curtains. It makes the proposed composition and glass treatment reviewable without a video decoder, remote media or runtime shader. Owner approval of the atmosphere does not imply approval of this as final production footage. A licensed natural-motion loop can replace it in a separately reviewed follow-up.

The original image was generated for this project, not taken from an external asset library; there is no third-party attribution dependency. No claim of exclusive copyright in AI-generated imagery is made.
