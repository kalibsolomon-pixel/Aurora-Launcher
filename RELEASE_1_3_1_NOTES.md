# Aurora Launcher 1.3.1 — release notes

Aurora Launcher 1.3.1 is a corrective update to the 1.3.0 interface. Aurora Client 2.1.5
remains the current production client for new compatible instances, and existing
instances remain pinned to their selected releases.

### Corrections

- The Aurora Borealis background now shows gentle internal movement — soft
  light patches that brighten, ripple, and fade within a stable overall
  silhouette — while the composition stays anchored with no drifting or
  panning of the whole scene.
- The account dialog uses the same frosted-glass treatment as the rest of the
  launcher, with translucent layered surfaces over a dimmed Borealis
  background; the OLED/Simple themes keep their opaque treatment.
- Borealis playback now reliably pauses while the launcher window is
  minimized and resumes from the same position when the window is restored,
  so a minimized launcher no longer keeps the animated background decoding.
- Existing settings, accounts, instances, and selected instance carry over
  from 1.3.0 unchanged.

This release does not change Minecraft compatibility, Aurora Client behavior,
authentication, or the existing Discord privacy controls.
