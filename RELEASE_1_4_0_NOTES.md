# Aurora Launcher 1.4.0 — release notes

Manage more of your Minecraft setup from Aurora, with clearer updates and safer changes.

- Browse and manage Modrinth mods, resource packs and shaders with clearer source and compatibility information.
- Install supported Modrinth modpacks and review pack updates while preserving your local changes.
- Update managed content together, with dependency checks and recovery when an operation fails.
- Create supported NeoForge instances alongside Fabric and Vanilla instances.
- Check for Aurora Client and Launcher updates in one place. One Update action handles available updates, with concise progress and Retry controls.
- Improved validation and preservation of accounts, instance settings and user content during changes.

Production-client correction — October 7, 2026: the current production target is Aurora Client 3.0.0 for Minecraft 1.21.11. Corrected Launcher source selects it for new compatible Aurora instances. Existing instance pins are preserved; nothing updates automatically.

The published 1.4.0 installer retains its original creation catalog. Follow the 1.4.1 manual-installation guidance, then use Check for Updates and explicitly apply the Aurora Client 3.0.0 update after creating a compatible instance. This correction does not replace historical installer bytes. See `CLIENT_3_0_0_PRODUCTION_CORRECTION.md`.

Launcher updates use signed installers verified by Aurora.
