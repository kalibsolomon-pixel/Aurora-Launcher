# Aurora Launcher Native 2.1.0 — Interface and Gameplay Improvements

## Improved

- Unified Mods, Resource Packs and Shaders lists with larger icons and improved artwork handling.
- Redesigned Accounts and Downloads drawers, easier Settings navigation and more visible toggles.
- Refined Home widget placement, resizing and snap-to-grid behavior.
- Redesigned Playtime widget with 7-day, 30-day and all-time activity charts.

## Added

- Skin-library favorites.
- Recent multiplayer server and singleplayer world tracking.
- Saved-server and saved-world browsing with separate Saved, Recent and Favorites views.
- Multiplayer and singleplayer Quick Play.
- Recovery of surviving gameplay-history records after Launcher restart.

## Preserved

- Low-overhead native rendering and existing account and authentication features.
- Modpack integrity protections, user instance data and settings, and signed native updates.
- Optional Aurora Client integration.

Extremely rapid gameplay transitions can occasionally overwrite Minecraft's built-in activity record before Aurora observes it.
