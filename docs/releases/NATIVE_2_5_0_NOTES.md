# Aurora Launcher 2.5.0

**A cleaner, more focused interface.** Every surface across Home, Instances,
Discover, Pulsar, Skins, Sync, and Settings now follows one restrained visual
system with full-pill active states, a single violet accent, status-only green
indicators, and text-first settings and instance options.

**Floating download notifications.** Downloads no longer occupy a dedicated
sidebar page. Active installs and finished notifications appear in a compact
bottom-right toast stack with inline progress, cancel, retry, and automatic
fade-out.

**Sharper Home and Instances.** The Home hero is a compact two-line card with a
borderless instance switcher, leaving prime space for customizable widgets,
cached server icons, and playtime charts. Instances use a roomier two-column
grid, unified breadcrumbs, and a single scrolling Options view.

**Richer Discover browsing.** Mod cards place download counts beside project
names, show live install status, and open a native in-app Modrinth project
detail popup with gallery, description, and direct install controls.

**Pulsar PvP combat breakdown.** Synced with Aurora Client 3.7.0 analytics:
single-fight summaries now present structured Key takeaways alongside first-hit
rate and hit trade ratio, Defense adds health and absorption timelines plus
shield disable punish metrics, and Flow adds Exchange openers & trades and Key
PvP turning points tables.

**Faster downloads and smaller builds.** Core metadata and artifact transfers
now use HTTP/2, buffered verified streaming, and parallel library acquisition,
while compressed bundled icon tables and tuned release optimization shrink the
native binary and reduce memory use.

Update trust, application identity and managed-data locations remain unchanged.
Windows publisher signing remains unconfigured; signed update artifacts provide
release authentication.
