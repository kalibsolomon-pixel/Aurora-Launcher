# Aurora Launcher 1.3.0 — release notes

Aurora Launcher 1.3.0 refreshes the launcher interface around Play while keeping
Aurora Client 2.1.5 as the current production client for new compatible
instances. Existing instances remain pinned to their selected releases.

### Launcher interface

- A larger Play-focused Home layout, separate player showcase, icon navigation,
  and custom Aurora window controls on Windows.
- Home widget edit mode for arranging, sizing, showing, and hiding widgets.
- Reorganized Settings with independent theme, background, and accent choices.
- An optional 20-second looping Aurora Borealis background with adjustable
  motion speed, a still fallback for reduced motion, and playback pause while
  the launcher is inactive or hidden.
- Shared frosted-glass styling across Home, Instances, Settings, and instance
  content panels, with refinements to spacing, cards, icons, and focus states.

The new appearance settings migrate from existing launcher configuration;
previous theme, accent, widget, instance, and account choices are preserved.
This release does not change Minecraft compatibility, Aurora Client behavior,
authentication, or the existing Discord privacy controls.

On Windows, the custom title bar does not currently expose the native Snap
Layouts flyout on maximize-button hover. Windows keyboard snapping remains
available.
