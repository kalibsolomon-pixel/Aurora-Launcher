# Aurora Launcher 2.3.0

**Pulsar fights in the launcher.** A new Pulsar page keeps every fight Aurora
Client records in a library that stays in the launcher. It shows trends,
offense, defense, flow, history, opponents, personal records and settings.
Each fight has Summary, Offense, Defense, Flow, Playback and Evidence views,
and two fights can be compared side by side. Fights recorded by newer Aurora
Client builds use strict outcomes: Hit, Blocked, Disabled or Miss, with stuns
counted as Disabled and spam clicks not counted. Older recordings are read with
the same rules. Recording files are never modified.

**Game log and Kill.** A game log window streams the game's output live, with
search, warning and error filters, Copy all, Diagnose and an Upload to mclo.gs
that removes access tokens, account IDs, your home folder and user name first
and asks before sending. Turn on "Show game log window when launching" in
Settings to open it automatically. While a game is preparing or running, Play
becomes Kill. Stopping a running game asks first and ends only the game this
launcher started.

**Synced group.** On the Sync page, choose a main instance. Instances that join
the group take its settings; after that, a settings change made in any member
reaches the others before they next launch. This covers game settings, controls
and graphics, Aurora settings and profiles, and resource and shader packs,
across Minecraft versions where a setting means the same thing. Worlds,
waypoints, maps, counters, sound device and consent choices stay per instance.
Nothing is written while a game is running, and every change is backed up with
Restore available.

**Skins.** The Skins page is reorganized around your current look and a skin
library grid. Any saved library skin can now be applied to the signed-in
account, and the current skin and cape are clearly marked.

**Servers.** Home → Servers → Manage adds, edits, reorders and deletes an
instance's servers without opening Minecraft. Server rows are plain
destinations: Play joins the server from your current instance, and the same
server is listed once. Quick Play now works on Minecraft 1.20 and newer.

**Screenshots and content.** Each instance has a Screenshots tab with previews,
Copy image, Copy file, Reveal, Rename and Delete to the Recycle Bin. Import
local content opens the Windows file picker.

Update trust, application identity and managed-data locations remain unchanged.
Windows publisher signing remains unconfigured; signed update artifacts provide
release authentication.
