# Aurora Launcher 2.2.1

Installed mods, resource packs and shaders load together in one scrollable list,
without pagination. Compact rows keep artwork, names, toggles and Delete actions
aligned. Dependency notes expand only their own row.

Home widgets now use finer click-and-drag positioning and resizing by default.
Drag previews
show the resulting arrangement before saving. Existing layouts retain their
dimensions; resizing the window does not rewrite saved geometry.

The installer defaults to removing the previous launcher executable after a
successful upgrade, preserving instances, mods, worlds, accounts, settings and
other app files. Uncheck the recommended option to retain the prior program as
`aurora-launcher.previous.exe`. Silent in-launcher upgrades use the same default.
An existing retained backup is never overwritten.

Newly customized fine-grid layouts require 2.2.1 or later. Before downgrading,
reset Home's layout in a supporting version. Update trust, application identity
and managed-data locations remain unchanged. Windows publisher signing remains
unconfigured; signed update artifacts provide release authentication.
