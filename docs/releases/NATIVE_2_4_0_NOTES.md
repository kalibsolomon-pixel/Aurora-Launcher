# Aurora Launcher 2.4.0

**A simpler launcher.** The sidebar is now a rail of larger icons, still
grouped by Play, Library and Profile, with each name shown on hover or
keyboard focus. Content now lives inside each instance: open an instance for
Overview, Content and Settings tabs.

**One Home card.** The selected instance and the instance switcher are now one
card. Click the instance name to switch instances or open Manage instances.
The Aurora Client update card is gone: when a newer launcher or Aurora Client
is available, a dot appears on Settings and on Updates & About, where updates
are reviewed and applied.

**Bigger widgets.** Server rows have larger icons and text and scroll inside
the widget. The Media widget shows larger album art, title and artist.

**Modrinth project pages.** Details opens a project window with the full
description, gallery, changelog and versions. Choose a Minecraft version, then
a loader, then the exact release to install; the newest compatible stable
release is preselected and dependencies are listed by name. Discover and
Content cards are larger and arranged in a responsive grid.

**Import folders.** Choose folder or drag in an extracted Modrinth modpack,
a resource or shader pack folder, or a folder of mod jars. Extracted
CurseForge packs import only when every file is included.

**Discord Rich Presence works.** The launcher now connects to Discord at
startup, reconnects if Discord opens later, and shows In Launcher or Playing
Minecraft with elapsed time. Settings → Discord shows the real connection
status and can reconnect.

Update trust, application identity and managed-data locations remain unchanged.
Windows publisher signing remains unconfigured; signed update artifacts provide
release authentication.
