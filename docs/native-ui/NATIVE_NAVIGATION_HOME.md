# GPUI navigation and Home

The 80 px navigation rail groups Play, Library, Profile, and launcher actions
with dividers. The rail compresses at short heights. Icons have accessible
names and show their labels on hover or keyboard focus. Downloads shows its
active count.

Instances opens to a grid. An instance opens to Overview, Content, and
Settings, with a back action to the grid. The Content manager is scoped to
that instance. Discover's installed links and its return action open the same
Content tab. Home's Edit instance opens the selected instance's Settings tab.

Home combines the active instance, Play, Game log, Edit instance, and playtime
totals in one card. The instance name opens a keyboard-navigable list of all
instances with a Manage instances footer. Escape and a click outside dismiss
the list. The activity totals move below the actions at narrow widths.

Settings > Updates & About contains the launcher update controls and the
review and apply flow for Aurora Client updates. Startup and manual checks
report Client availability for each installed instance. A pending launcher
or Client offer marks both the Settings rail and the Updates & About tab.
Checking and selecting an instance to review do not apply an update. The
Client review and apply still use the original verified artifact and
fingerprint checks.

The Servers widget uses 80 px rows with 44 px favicons and a scrollbar when
the list overflows. Media uses up to 128 px of artwork and adjusts typography
and transport placement to the rendered card. Resizing the window leaves
saved widget geometry intact.
